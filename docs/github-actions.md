# GitHub Actions 실습 안내

GitHub Actions 첫 실습은 [Week 6 실습서](week-06-lab.md)에 통합했다.
해당 문서 하나에서 공개 로그 분석, 본인 PR 제출, API 없는 연습, 승인된 실제 실행,
Phoenix 결과 확인과 제출 기록까지 진행한다. 관리자 설정도 같은 문서의 접기 항목에 있다.
별도 대본·진행표는 필요 없다.

- A: 공개 PR의 실패·수정 후 성공 읽기
- B: 본인 PR의 코드 검사 확인 — 모델 API 0회
- C: 준비·승인 후 배정된 nightly·weekly 결과 분석과 사람 결정

A·B 성공은 C 완료나 새 답의 품질 통과가 아니다. 현재 배포·승인 상태와 실행 상한도
Week 6 실습서에서 확인한다.
